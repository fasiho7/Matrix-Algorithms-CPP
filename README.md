# Matrix-Algorithms-CPP
A collection of efficient 2D array and matrix manipulation algorithms implemented in C++.

## 🚀 Problems Solved
1. **Find Largest Element**: Traverses a dynamically allocated 2D array using pointer arithmetic.
2. **1D to 2D Transformation**: Reconstructs a flat array into an $m \times n$ matrix.
3. **Negative Count**: Optimized search for negative numbers in a sorted matrix.
4. **Diagonal Sum**: Calculates the sum of primary and secondary diagonals in $O(n)$ time.

## 🛠️ Technical Focus
- Pointer Arithmetic
- Dynamic Memory Allocation
- Algorithmic Optimization (Time & Space Complexity)

## How to Run
Compile using any C++ compiler:
`g++ main.cpp -o matrix_sol`
